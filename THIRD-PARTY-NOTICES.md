# Avisos de terceiros

O Atalaia Acessos é software livre, sob a GNU GPLv3 (ver [LICENSE](LICENSE)), e é
feito em cima do trabalho de muita gente. Esta é a lista do que de terceiros vai
nos pacotes, com a versão e a licença de cada um, e no fim os textos das
licenças. Ela é gerada por `scripts/avisos-terceiros.py` a partir do que os
builds de fato empacotam; não edite à mão.

## Bibliotecas C do pacote Linux (Flatpak)

Compiladas junto com o app pelo manifesto (`flatpak/org.jj.Acessos.yml`). O resto
do que o app usa no Linux vem do runtime `org.freedesktop.Platform`, instalado à
parte pelo Flatpak, e não é distribuído por nós.

| Componente | Versão | Licença | Para que serve |
|---|---|---|---|
| [FreeRDP](https://www.freerdp.com) | 3.32.2 | Apache-2.0 | o cliente RDP |
| [LibVNCServer / LibVNCClient](https://libvnc.github.io) | 0.9.15, com três correções de segurança (ver `flatpak/patches/libvncserver/`) | GPL-2.0-or-later | o cliente VNC |
